# LastProjectJava - Hệ thống Cào Dữ Liệu Tự Động

Hệ thống tự động cào dữ liệu bài nộp từ Codeforces và Vjudge, lưu trữ vào cơ sở dữ liệu SQL Server.

## 📋 Yêu cầu

- Java JDK 11+
- Maven 3.6+
- SQL Server 2016+ (Windows Authentication)
- Microsoft Edge

## 🚀 Cài đặt

- Mở SQL Server Management Studio
- Chạy file `database_setup.sql` để tạo database và bảng

## 🏃‍♂️ Chạy chương trình

- Chạy file main

## 📖 Sử dụng

1. Chạy chương trình
2. Chọn nền tảng: 1 (Codeforces) hoặc 2 (Vjudge)
3. Nhập số ngày muốn cào (mặc định: 2)
4. Nhập username (có thể nhiều, cách nhau bằng dấu phẩy)
